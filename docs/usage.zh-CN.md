# CONST API 使用指南

[README](../README.zh-CN.md) · [English](usage.md) · [源码构建](../SOURCE.zh-CN.md)

本指南介绍桌面应用。模型市场和账号功能仅适用于官方下载版本；
从公开源码编译的是本机版。

## 安装与启动

从 [Releases](https://github.com/llxisdsh/const-api-public/releases/latest) 下载对应系统的安装包，
或按[本机版构建说明](../SOURCE.zh-CN.md)编译。macOS 建议先把应用移入 Applications，再打开。
仅对可信来源文件按系统提示授权，不要全局关闭系统保护。

正常打开桌面应用即可。关闭窗口后程序驻留托盘或菜单栏；彻底停止网关请使用其中的**退出**。
已移除的 headless、检查、帮助和版本命令行模式不再支持；
托盘启动提示仅供登录自启动内部使用。

## 添加渠道并配置工具

1. 在**模型**页添加上游 API Key、受支持的订阅或本地服务。
2. 刷新渠道资料以获取模型元数据。模型测试或完整检查会实际发起推理请求，可能消耗上游额度。
3. 启用渠道，在**使用**页等待**本地 API · 运行中**。
4. 选择工具并应用配置，按提示重启工具。需要恢复时使用**取消配置**。

渠道可用和工具能力是两回事：文本请求成功不代表图片、工具调用或所有 Responses 功能均可用，
应结合渠道检查结果和最终请求错误判断。

服务商凭据填在渠道中；**使用**页显示的是本地网关 Key，手动配置工具时应填写这个 Key。

自动配置会备份改动，恢复时保留后来无关的用户修改。不要同时让官方版和本机版管理同一工具。
Codex 应保留原来的 home 和会话目录；切换 provider 后若历史看似消失，不要删除会话文件。

## 手动接入 API

始终以界面当前显示的地址和 Key 为准。官方版默认端口为 `38787`，
源码本机版默认为 `38789`。

| 原生协议 | 源码本机版 Base URL | 常用接口 |
| --- | --- | --- |
| OpenAI | `http://127.0.0.1:38789/v1` | `/models`、`/responses`、`/chat/completions` |
| Anthropic | `http://127.0.0.1:38789/anthropic` | `/v1/messages` |
| Gemini | `http://127.0.0.1:38789/gemini` | `/v1beta/models/{model}:generateContent` |

例如，用本地 Key 读取模型列表：

```sh
curl http://127.0.0.1:38789/v1/models -H "Authorization: Bearer <local-api-key>"
```

Windows PowerShell 中若 `curl` 是别名，请使用 `curl.exe`。占位符只在本机替换，
不要把真实 Key 放进要分享的终端记录、截图或 Issue。
使用接口返回的模型 ID，不要根据展示名称猜测。HTTP 和受支持的 WebSocket 操作共用本地端口。

## 本机路由和局域网共享

自己的渠道直接向配置的上游发送请求。本机版不会回退到平台市场；
官方版的本机优先和兼容模型替代行为由相应设置决定。

在**局域网共享**中选择允许的模型，为成员分别创建 Key 和用量限制。
使用弹框显示的地址，仅向可信子网放行防火墙。本地 HTTP 未加密，
不要把监听端口直接暴露到公网。

## 官方模型市场

使用官方客户端登录后，可使用或供应市场模型。使用前查看价格和路由设置。
市场请求经过平台及选中的供应端，服务商凭据保留在供应端电脑上。
额度、模型能力、可用性和价格都可能影响选择。公开源码本机版不包含这项服务。

## 文件和问题排查

官方版数据目录为 `~/.const-api`，本机版为 `~/.const-api-local`。
其中包含配置、工具备份、托管字段记录和滚动日志。
服务商 Token、渠道导入文件均属于敏感资料。

| 问题 | 检查方法 |
| --- | --- |
| 本地 API 未运行 | 检查界面端口、端口占用或系统保留端口，以及最近运行日志；解决原因后重启应用。 |
| API Key 无效 | 使用**使用**页的 Key，而不是服务商 Key；更改本地 Key 后重新配置工具。 |
| 没有模型或可用路由 | 启用健康渠道，核对精确模型 ID、额度、并发和请求能力；上游变化后刷新资料。 |
| 工具配置未生效 | 完全关闭工具后重开；仍无效时，先取消托管配置、重启至正常模式，再重新配置。 |
| Codex 历史看似消失 | 保留原会话目录，重新应用目标 provider 或取消托管配置，不要删除历史。 |
| 源码版涉及平台接入 | 内置平台功能不可用；请配置自己的上游，或使用官方客户端。 |

标准日志用于排查，不用于保存提示词和回复正文。显式开启原始流量调试的特殊构建可能记录敏感正文，
不要未经检查就上传。反馈问题请注明版本类型、版本号、系统、复现步骤和脱敏错误，
不要上传完整账号或配置文件。
