CONST API 给 AI 工具一个统一的本地入口。工具只需配置一次，自己的模型可以直接用，缺少的模型可以去共享市场找。支持 Windows、macOS 和 Linux。

## 为什么用 CONST API？

- **配置一次。** 换 API Key、受支持的订阅、本地模型或市场模型，不必逐个重配工具。
- **先用自己的。** 自己的模型渠道可用就直接使用；没有或不可用时，自动转到模型市场。
- **不用办齐所有账号。** 自己没有某个模型，也可以使用别人共享的可用渠道。
- **每笔使用都看得明白。** 价格参考显示市场预估价；使用日志显示实际模型、Token、线路和费用。
- **改工具也能安全退出。** 自动配置会先备份，取消配置不会覆盖你后来的修改；Codex 切换接入时仍保留同机历史会话。

## 模型市场是干什么的？

模型市场把“需要模型的人”和“有空闲模型渠道的人”连接起来。

- **需要模型：**直接使用别人共享的可用渠道，按成功请求的实际用量付费。
- **有空闲渠道：**把 API 渠道、受支持的订阅或本地模型按自己的报价共享出去；请求成功完成后获得供应收益。

每次使用市场时，CONST API 会先找同名模型，再从价格上限内健康可用的渠道中优先选择低价线路。活动会话尽量保持稳定，渠道失败后自动避开。使用前可以查价格，使用后可以核对结果。

渠道凭据不会进入市场，只保存在运行渠道的电脑上。平台只接收路由所需的模型、能力、状态、容量和报价。共享请求仍需经过平台，发送到实际供应端和模型服务商才能完成。

## 开始使用

1. [下载](https://github.com/llxisdsh/const-api-public/releases/latest)并打开 CONST API。
2. 看到**本地 API · 运行中**后，点击工具图标。连接配置由 CONST API 自动完成。
3. 登录后可以使用模型市场；打开**模型**页，可以加入自己的 API 渠道、受支持的订阅或本地模型。

需要手动填写地址或使用命令行？请看[使用指南](docs/usage.zh-CN.md)。

## 价格怎么算？

- **自己的渠道：**只承担模型服务商、订阅或本机运行成本，CONST API 不改变这些价格。
- **模型市场：**优先使用价格低且可用的渠道。使用前能看价格，使用后能在**使用日志**核对实际用量和费用。

## 安全和隐私呢？

- AI 工具只连接本机地址 `127.0.0.1:38787`。
- 使用自己的渠道时，请求从这台电脑直接发给模型服务商或本地模型，不经过 CONST API 平台。
- 使用市场渠道时，请求会经过平台，再发送给实际供应端和模型服务商。
- 日志不保存提示词、回复正文、API Key、账户 Token、Cookie 或鉴权请求头。
- 修改工具配置前会先备份。取消配置时只撤回 CONST API 的修改，你后来改过的内容会保留。

## 技术特点

- **原生 API 接口。** OpenAI Responses / Chat Completions、Anthropic Messages 和 Gemini 原生接口共用一个本地网关；API 渠道、受支持的订阅、本地模型和市场渠道都接入同一套模型渠道系统。
- **能力级协议处理。** 请求、响应、流式事件、错误、用量和工具调用遵循同一套操作契约；同协议尽量原样透传，只在需要时进行跨协议转换。
- **低价优先的稳定路由。** 精确模型和自己的渠道优先；进入市场后，综合可用性、报价、额度、并发、成功率和延迟选择渠道，并保持活动会话稳定、自动避开失败渠道。
- **可撤销的工具配置。** 对 JSON、JSON5、YAML 和 TOML 做结构化修改，先备份再原子写入；字段级三方恢复会保留用户后来的修改，Codex 切换接入时仍保留同机历史会话。
- **可验证的动态目录。** 模型、兼容组、能力、价格、工具元信息和平台端点通过 Ed25519 签名、内容寻址的独立版本更新；全部校验通过后才原子切换，客户端和服务器始终保留已验证快照。
- **可复算的用量与结算。** 每次请求开始时冻结模型、价格和供应报价，结束后把实际用量、线路、费用和结算证据写入账本与使用日志。
- **自适应传输。** 平台请求优先 HTTP/3，并自动回退到 HTTP/2 或 HTTP/1.1；供应连接优先 QUIC、回退 WebSocket，同时支持远程加密连接和协商压缩。
